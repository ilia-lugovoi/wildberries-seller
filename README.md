# Wildberries Seller Analytics
## Цели проекта
Создать BI-аналитику для селлера на WB, которая даст возможность принимать своевременные и правильные решения

## Технологии
- Python — ingestion и первичная валидация данных
- PostgreSQL — хранение данных
- dbt — staging, intermediate и marts
- Power BI — визуализация и аналитика

## Источники данных
WB API и справочники селлера

## Архитектура
### ingestion

1. extract: csv_reader и excel_reader
2. transform: column_names и validation
3. load: postgres

- logger для записи INFO
- settings для эффективности кода
- main.py - оркестрация ingestion

### dbt

1. staging layer
2. intermediate: группировка столбца номенклатуры
3. marts:
   mart_sales_daily: обработка и агрегация продаж, и их соединение с справочниками
   mart_warehouse_inventory_daily: обработка и агрегация склада, и его соединение с stg_cost_price
   mart_sales_for_inventory: подготовка продаж для финальной витрины mart_inventory_with_sales_daily
   mart_inventory_with_sales_daily: обработка, агрегация и соединение витрин продаж и складов
   dim_change_date: таблица даты для визуализаций
