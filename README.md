# Wildberries Seller Analytics
## Цели проекта
1. Создать архитектуру, которая гарантирует корректную обработку данных из API и справочников для их дальнейшего анализа
2. Создать четыре BI-отчета, которые напрямую помогут повысить KPI селлера

## Технологии
- Python — ingestion и первичная валидация данных
- PostgreSQL — хранение данных
- dbt — staging, intermediate и marts
- Power BI — визуализация и аналитика
- Docker — локальное окружение
- Git/GitHub — версионирование проекта

## Источники данных
WB API и справочники селлера

## Архитектура
### ingestion

1. extract: csv_reader и excel_reader
2. transform: column_names и validation
3. load: postgres

- logger для записи INFO
- settings для эффективности кода
- main.py - оркестрация ingestion

### dbt

1. staging layer
2. intermediate: группировка столбца номенклатуры
3. marts: обработка, агрегация и соединение со справочниками продаж
